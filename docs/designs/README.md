The Django e-commerce portfolio project is the shared example. Product views and
architecture diagrams are conceptual, rather than screenshots of the deployed
product or claims about its internal implementation. Every concept includes the
project narrative, stack, source/demo actions, next-project navigation and footer.
Desktop proposals retain the portfolio sidebar; mobile proposals use the compact
header and a single column.

The [design system](../../.stitch/DESIGN.md) and
[capture brief](../../.stitch/BRIEF.md) describe the original portfolio reference.
Structural inspiration came from [BarnesInside](https://barnesinside.is-a.dev/)
and [the reference portfolio](https://my-portfolio-psi-flax.vercel.app/).
Their screenshots and extracted DOM are not included here.

Private Stitch project state, API responses, authentication helpers, local
captures and older drafts remain local and are excluded by `.gitignore`.
