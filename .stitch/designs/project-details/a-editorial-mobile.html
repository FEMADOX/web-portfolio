Estructura Editorial & Planteamiento

Visión general y planteamiento del proyecto

Una plataforma full stack desarrollada con Django y Python, PostgreSQL como base de datos y Stripe para los pagos. El proyecto reúne las funciones de una tienda: catálogo e inventario, carrito, autenticación, pedidos y paneles de clientes.

El recorrido conecta la selección de productos con el carrito y el pago, y continúa con la gestión de los pedidos. Las vistas conceptuales de esta página ayudan a explicar esas funciones; el repositorio muestra su implementación.

Puntos destacados
  • Gestión de inventario con base de datos relacional.
  • Gestión de pedidos y paneles de clientes.
  • Autenticación y perfiles para seguimiento de clientes.

Qué construí

Diseñé e implementé la solución de extremo a extremo cubriendo tanto la interfaz de usuario como la lógica en el servidor y la persistencia de datos:

1. Catálogo interactivo

Funciones de catálogo e inventario para presentar y gestionar productos.

2. Flujos de carrito

Flujos de carrito que conectan la selección de productos con el proceso de compra.

3. Integración de pasarela Stripe

Integración de Stripe como proveedor de pagos del proyecto.

4. Gestión de inventario y pedidos

Gestión de pedidos y paneles de clientes dentro de la plataforma.
